# 🎵 Spotify Clone

A simple **Spotify Clone** built using **HTML, CSS, and JavaScript**.  
This project replicates the basic interface and functionality of the Spotify music player.

The main goal of this project is to practice **front-end web development** by building a music player UI similar to Spotify.

---

## 🚀 Features

- 🎵 Play and pause songs
- ⏭ Next and previous track controls
- 📊 Song progress bar
- 🔊 Volume control
- 🎧 Playlist / song list interface
- 📱 Responsive UI design

---

## 🛠 Tech Stack

- HTML
- CSS
- JavaScript

---

## 🎯 Learning Outcomes

- Understanding of **HTML structure**
- Styling with **CSS**
- Adding interactivity using **JavaScript**
- Building a **music player UI**
